网络部署图应该怎么画

How to draw a network deployment diagram

网络部署图的本质是把“信任边界、分区、设备、链路与访问关系”讲清楚。专业拓扑遵循自上而下的分层约定：互联网（云）→ 边界防火墙 → 核心层 → 汇聚层 → 接入层 → 终端，让人一眼能找到防火墙这道信任边界。半导体工厂还要叠加 IT/OT 分离与工艺区微隔离。标准做法分 8 步：

01

定范围与受众

区分物理拓扑（机柜、布线、链路）与逻辑拓扑（VLAN、路由、安全域）；先画一张总览，再按站点/分区出详图。

02

选参照模型

企业网用核心-汇聚-接入三层模型；工控网用 Purdue/IEC 62443 分区（L0~L5），半导体遵循 SEMI E187。

03

分区分域

按业务与安全等级划分安全 Zone 与 VLAN：办公、DMZ、服务器、iDMZ、MES、各工艺机台区、管理网，域间默认拒绝。

04

清点资产与图标

统一符号：云=互联网、砖墙=防火墙、圆柱=路由器、矩形=交换机、机架=服务器；同类型设备用同一套图标与配色。

05

画链路与标注

标注设备名、VLAN ID、网段/掩码、IP、带宽（10G/40G）、协议（OSPF/BGP/HSMS）、主备与 Trunk 关系。

06

标信任边界与策略

用防火墙/网闸图标明确边界，附“源→目的→端口→动作”策略矩阵；高可用（HA/双上联/双ISP）单独标注。

07

图例/标题/版本

每张图配标题、图例、比例尺或说明、版本号、编制人/日期与变更记录，便于评审与后续维护。

08

校验与评审

核对无孤岛、无越权直连、无地址冲突；与安全、运维、厂务会签，落地后随变更持续更新。

标注最小集合：设备主机名与型号 · 接口/端口 · VLAN ID · IP 地址与掩码 · 网关 · 链路带宽与介质（光纤/无线用虚线）· 安全域归属 · 主备/HA 关系。缺这些信息，图就只能“看个样子”，不能用于实施。

集团广域互联拓扑（多子公司 / 多厂区）

Group WAN · MPLS + SD-WAN dual-plane

采用双平面广域架构：底层是运营商 MPLS 专线骨干（SLA 保障，承载 MES/生产实时与核心同步流量）；上层是 SD-WAN Overlay（Internet+MPLS 双链路，GRE over IPsec 加密、应用感知选路）。各站点内网网段互不冲突，总部 Fab1 作为路由反射器（RR），BGP AS 65000，骨干互联地址统一使用 10.255.0.0/16。

OT 生产机台网络详图（工艺区微隔离）

Equipment network · micro-segmentation

机台网络采用“EAP → OT 汇聚 → 工艺区工业防火墙 → 工业接入交换机 → 机台”四级结构。每个工艺区是独立 VLAN/子网，区与区之间默认拒绝、白名单放行，光刻/刻蚀等关键区没有通往其他区的直连路径。机台只与 EAP 经 HSMS（SEMI E37，TCP 5000）/ GEM（E30）通信，HSMS 本身无认证加密，安全完全依赖网络隔离。

办公 VDI 桌面云架构（瘦终端 / 零终端）

Virtual Desktop Infrastructure

全公司办公与车间终端统一采用 VDI 桌面云：终端只负责显示与输入（无本地数据、无硬盘），桌面、数据与应用集中在数据中心运行，便于统一镜像、补丁、防泄密与灾备。终端经 连接服务器（Connection Broker，HA）分配桌面，AD 统一认证，关键场景双因子。

防火墙分层与访问控制策略矩阵

Firewall layers & policy matrix
